🧭 CAIRN SEARCH — STATE-SPACE SEARCH FACT-INTENT GRAPH
A general state-space search engine: given an ORIGIN and a GOAL it searches for a path through an unknown space on a blackboard of Facts (confirmed findings), Intents (declared-but-unexplored directions) and Hints (your judgment, injected live and absorbed on the next reasoning round). Tasks are synthesized at runtime from the graph's own state — bootstrap tries the goal directly, reason decides what is worth exploring, explore claims exactly one intent and returns exactly one fact. Coordination is stigmergic: tasks see only the board. Techniques reimplemented from oritera/Cairn (AGPL-3.0) — no upstream code vendored.
